# PROBATIO v0.1.2

Copyright 2026 Abdelmadjid Djemaï

This patch adds an independent check of the two reference-verifier proofs. The Lean definitions, proofs, five examples, Python verifier and its fifteen tests are unchanged from v0.1.1. This release is distributed under [Apache-2.0](../LICENSE).

The tag triggers the [Lean, Python and source archive checks](../.github/workflows/ci.yml) and the [independent proof check](../.github/workflows/independent-check.yml). The latter exports the proof terms for `Probatio.verifier_correct` and `Probatio.verifierCle_correct` with the Lean 4.15.0 exporter, then checks them and their dependencies with nanoda (Rust). Both tools are pinned. The workflow retains the exported declarations, checker configuration and verdict.

The proof applies to exact matches across two admissible batches of already-decoded volumes. The Python file reader and formal equivalence with the Lean verifier remain outside its scope.
